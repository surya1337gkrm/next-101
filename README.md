Steps for configuring prisma and sqlite

- install prisma as dev dependency [ npm i - D prisma ]
- configure prisma with sqlite as the data source [ npx prisma init --datasource-provider sqlite ]
- use the url as "file:app.db" in dev env and replace with respective db url in other envs
- add /prisma/app.db in the gitignore file
- add model(s) schema in the prisma.schema file and run the migration [ npx prisma migrate dev --name init ]
- above command will create a new database file named app.db in the root directory of your project and run the migration to create the tables based on the schema defined in the prisma.schema file.
